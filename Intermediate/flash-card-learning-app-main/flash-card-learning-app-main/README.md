\# 📚 Flash Card Learning App



A flash card application built with \*\*Python\*\*, \*\*Tkinter\*\*, and \*\*Pandas\*\* to help users learn French vocabulary.



\## ✨ Features



\- Random flash cards

\- Automatic card flip

\- Save learning progress

\- CSV data management

\- Clean graphical interface



\## 🛠️ Technologies



\- Python

\- Tkinter

\- Pandas

\- CSV



\## 🚀 How to Run



```bash

python main.py

```
