\# 🔐 Password Manager



A password manager built with \*\*Python\*\*, \*\*Tkinter\*\*, and \*\*JSON\*\*.



\## Features



\- Generate secure passwords

\- Save passwords in JSON format

\- Search saved credentials

\- Simple graphical interface



\## Technologies



\- Python

\- Tkinter

\- JSON



\## How to Run



```bash

python main.py

```
