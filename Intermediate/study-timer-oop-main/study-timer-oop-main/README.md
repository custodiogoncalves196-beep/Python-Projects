# ⏱️ Study Timer (OOP)

A modern Pomodoro-style study timer built with **Python** and **Tkinter**, following **Object-Oriented Programming (OOP)** principles.

## 📖 Overview

This application helps users stay focused by managing study and break sessions through a simple and intuitive graphical interface.

The project was developed to practice:
- Object-Oriented Programming (OOP)
- Tkinter GUI development
- Separation of responsibilities between classes
- Event-driven programming

---

## ✨ Features

- ⏳ Study timer
- ☕ Break timer
- ▶️ Start, Pause and Reset controls
- 🔔 Sound notification when a session ends
- 🖥️ Clean and modern interface
- 📚 Session management

---

## 🛠️ Technologies

- Python 3
- Tkinter
- Object-Oriented Programming (OOP)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/custodiogoncalves196-beep/study-timer-oop.git
```

Go to the project folder:

```bash
cd study-timer-oop
```

Run the application:

```bash
python main.py
```
